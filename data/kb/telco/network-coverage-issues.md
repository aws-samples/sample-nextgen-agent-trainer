# Network Coverage and Signal Issues

## Coverage Verification
**Check coverage:**
- Use coverage map at anytel.com.au/coverage
- Enter postcode or address for detailed coverage
- Indoor coverage may vary from outdoor

## Signal Troubleshooting
**Basic steps:**
1. Restart device (power off/on)
2. Check for network outages at anytel.com.au/outages
3. Remove and reinsert SIM card
4. Reset network settings

## Network Selection
**Manual network selection:**
- iPhone: Settings > Cellular > Network Selection
- Android: Settings > Mobile Networks > Network Operators
- Select "AnyTel" from available networks

## Coverage Issues Resolution
**Poor indoor coverage:**
- Wi-Fi calling available on compatible devices
- Signal booster options available ($199)
- Femtocell for business customers

**No coverage areas:**
- Check if location is in coverage map
- Report new coverage gaps via MyAnyTel app
- Temporary roaming on partner networks in remote areas
