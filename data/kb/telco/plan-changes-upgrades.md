# Plan Changes and Upgrades

## Plan Change Process
**Immediate changes:**
- Upgrades take effect immediately
- Downgrades take effect next billing cycle
- Pro-rated charges apply for upgrades

## Mobile Plan Changes
**Essential to Premium/Unlimited:**
- No contract extension required
- Additional data available immediately
- $20 plan change fee waived for upgrades

**Downgrade restrictions:**
- Must complete current contract term
- Early termination fees apply if downgrading before contract end
- Data allowance reduced next billing cycle

## Fixed Line Plan Changes
**Speed tier changes:**
- NBN speed changes take 1-2 business days
- No technician visit required for most changes
- $49 plan change fee for downgrades

## Contract Extensions
**New device with plan:**
- 24-month contract extension
- Device payment plan available (0% interest)
- Early upgrade available after 12 months (50% device cost)

## Add-ons and Extras
**Available add-ons:**
- International calling packs: $10-30/month
- Extra data: $10/5GB
- Premium content subscriptions
- Device insurance: $12/month
