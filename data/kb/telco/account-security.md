# Account Security and Privacy

## Account Verification
**Required for account access:**
- Account holder name and date of birth
- Service number or account number
- Security PIN (4 digits)
- Recent bill amount or payment method

## Password Reset
**MyAnyTel app/website:**
1. Click "Forgot Password"
2. Enter mobile number or email
3. Verification code sent via SMS
4. Create new password (8+ characters, mixed case, numbers)

## Authorized Users
**Adding authorized users:**
- Account holder must call 131 234
- Provide authorized user's full name and DOB
- Authorized user can make plan changes but not account closure

## Privacy and Data
**Information we collect:**
- Usage data for billing and network optimization
- Location data for emergency services
- Marketing preferences can be updated in MyAnyTel

**Third-party sharing:**
- Credit reporting agencies for credit checks
- Law enforcement when legally required
- Marketing partners (opt-out available)

## Fraud Prevention
**Suspicious activity indicators:**
- Unexpected international charges
- Multiple failed login attempts
- Unusual data usage patterns
- Requests to change contact details

**If fraud suspected:**
1. Immediately suspend services via MyAnyTel
2. Change account passwords
3. Contact fraud team: 1800 123 456
4. File police report if required
