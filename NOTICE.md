# NextGen Agent Trainer

## Notice

This project contains sample code that demonstrates the use of AWS services
for building an AI-powered customer service training application.

## Sample Data

The JSON files in `data/scenarios/` and markdown files in `data/kb/` are
synthetic datasets created for demonstration purposes. They do not contain
any real customer information or sensitive data.
